# 📊 Dmart Sales Dashboard

## 📌 Overview
A Power BI dashboard built to analyze Dmart retail sales data and generate insights on sales performance, customer behavior, product trends, and operational efficiency.

## 🛠 Tools Used
- Power BI
- Excel / CSV
- DAX

## 📈 Key Features
- Sales & Revenue Analysis
- Customer Demographics
- Product Performance
- Payment Mode Analysis
- Order & Shipping Insights

## 📂 Dataset
25,000+ retail transactions including customer, product, sales, and operational data.
